Setup quiz

The questions we’d ask if we were setting it up for you.

This is the actual intake — the same questions, in the same order, that we use to build a household from scratch. It takes about twenty minutes for the essential part, and it produces a written setup brief you can work from, keep, or send to us.

Nothing you type leaves your browser. Answers save as you go, so you can close the tab and come back.

Before you start

Answer what you can. Anything left blank gets a sensible default that is easy to change later — but say when you are guessing, because a guessed answer that looks like a fact is worse than a blank.

The questions are in the order that unblocks the most: who, when they’re here, what the house is, then the jobs. The first four sections are enough to start — the quiz will tell you when you reach that point, and you can stop there.

Three things worth agreeing before anything gets built

Which parts are facts, and which are guesses.

Anything invented gets flagged as invented. Assignments, intervals and which day a job lands on are the usual culprits — a guessed answer that looks like a fact is worse than a blank.

What you want to be true, versus what is true today.

A rota nobody follows is worse than no rota. Start from what already happens, then change it deliberately.

What happens when it is wrong.

Every guess has to be changeable in one tap by the person it affects — not only by whoever set it up.

About the quiz

How long does it take?

About twenty minutes for the four essential sections, and forty-five if you answer everything. You can stop at any point — the brief includes whatever you have answered so far.

Where do my answers go?

Into your own browser and nowhere else. There is no account, no upload and no server involved. Clearing your browser data clears the answers, so copy the brief when you are done.

Do I need to answer everything?

No. Blanks are fine and honest blanks are better than guesses — the brief marks what you left, so nothing invented gets mistaken for a fact later.

Can I do this with my partner?

It works well done together, and it works differently done separately — particularly sections 4 and 5, where two people often have quite different ideas about who currently does what.

What if my household does not fit these questions?

Then answer the ones that apply and write the rest in your own words. The questions exist to surface things people forget, not to constrain what a household can be.
